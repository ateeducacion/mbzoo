## Decision
Layers:
1. bun:test unit tests against committed deterministic fixtures (fixtures/files/,
   generated by fixtures/scripts/generate-fixture.ts; manifest records sha256).
2. Playwright E2E driving the built viewer (Chromium locally since bootstrap;
   Firefox/WebKit matrix tracked as TASK-002). axe-core integration planned
   (TASK-005).
3. Security tests inside unit suite: XXE/entity bombs, malformed XML,
   traversal names (sanitizeTarName cases).
4. Benchmarks stay out of CI until stable (prompt §22); timing evidence lives
   in experiments instead.

## Consequences
bun:test does not prove browser behavior — Playwright is the interop gate.
e2e specs must not use Bun-only APIs (learned: import.meta.dir).
